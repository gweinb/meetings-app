# Meetings

Prepare meetings, take minutes and track action items.

Open **https://gweinb.github.io/meetings-app/** in Chrome or Edge and sign in with your Meetings password (set it in the desktop app → Admin → Security). Optionally install it as an app.

This repository only contains the static web app. Your meeting data is never uploaded: it stays in the SQLite database `meetings.db` on your computer, and the app talks to the local Meetings service at http://127.0.0.1:4317.
